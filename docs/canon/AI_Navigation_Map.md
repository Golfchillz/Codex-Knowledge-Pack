traceability, and alignment with the current repository state.

## Navigation Rules

- Read before editing.
- Follow Current Project Truth.
- Preserve Canon.
- Verify repository reality.
- Do not assume missing information.
- Report conflicts before making changes.
- Keep changes within the approved scope.
- Use the relevant Knowledge Domain for the task.
- Escalate unresolved authority conflicts.

## Missing Information

If a required document cannot be found:

- Report it as `Missing`.
- Do not invent its contents.
- Do not silently replace it.
- Continue only when sufficient evidence exists.

## Conflict Handling

If Repository State conflicts with documentation:

- Report the conflict.
- Prefer verified Repository State for repository facts.
- Check Current Project Truth.
- Escalate unresolved governance conflicts.

## Escalation

Escalate to JARVIS when:

- Scope conflict
- Missing approval
- Repository inconsistency
- Release blocker
- Delivery risk
- Canon conflict affecting execution

Notify Narin when:

- Canon changes
- Current Project Truth changes
- Knowledge structure changes
- Documentation reorganization
- Architecture decisions
- Duplicate or deprecated knowledge is discovered

## Goal

Ensure every AI agent follows the same navigation path,
uses the same authoritative knowledge sources,
and maintains repository consistency.
