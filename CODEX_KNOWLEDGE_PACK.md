## Startup Workflow

AI ทุกตัวต้องดำเนินการตามลำดับ

1. อ่าน `AGENTS.md`
2. อ่าน `CODEX_KNOWLEDGE_PACK.md`
3. อ่าน `00-Workspace_Index.md`
4. อ่าน Current Project Truth
5. อ่าน Canon
6. อ่าน README
7. อ่าน Issue หรือ Task
8. อ่าน Pull Request
